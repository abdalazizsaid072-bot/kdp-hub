# KDP Hub — إدارة أعمال النشر 📚📈

أبلكيشن (PWA) بيتسطّب على **الموبايل واللابتوب** ومربوط بشيت **"ادارة العمل"** على جوجل درايف.

## فيه إيه؟
| الشاشة | بتعمل إيه |
|---|---|
| **الرئيسية** | إيراد الشهر ونموه، المحصّل، المستحقات، الفرص، التسليمات الجاية، وأهم الأفكار |
| **المشاريع والعملاء** | كل صفوف الشيت ككروت، بحث وفلاتر (متأخرة، انتظار عربون، عليها مستحقات…)، رسائل واتساب جاهزة، تسجيل دفعة، تغيير الحالة، تعديل وحذف |
| **التحليلات** | البيزنس بيكبر ولا بيقل، الإيراد الشهري، عدد المشاريع، الإيراد حسب الخدمة (ترجمة، تنسيق، نشر، غلاف، 3D، تسويق…)، أكبر العملاء، نسبة التحصيل، جدول بالأرقام |
| **الأفكار والنمو** | أفكار مبنية على أرقامك + خطة أسبوعية + مكتبة أفكار (KDP، Amazon Ads، 3D، تسعير، تسويق) |
| **المهام / المصروفات / Amazon Ads / ملاحظاتي** | بيتحفظوا في تابات جديدة في نفس الشيت (بتتعمل لوحدها أول مرة) |
| **الأدوات** | عرض سعر للعميل يتبعت واتساب، حاسبة أرباح KDP، مقاس الغلاف والكعب، حاسبة ACoS للإعلانات |
| **الإشعارات** | تذكير قبل التسليم، العربون المتأخر، المهام، وفكرة كل يوم — على الموبايل واللابتوب |

## التشغيل (مرة واحدة)
1. **ربط الشيت:** افتح الشيت ← Extensions ← Apps Script ← الصق `apps-script/Code.gs` ← غيّر `API_KEY` ← Deploy كـ Web app (Execute as: Me — Access: Anyone) ← انسخ رابط `/exec`.
2. **رفع الأبلكيشن:** اسحب فولدر `KDP-Hub` كله على [app.netlify.com/drop](https://app.netlify.com/drop) (مجاني) هتاخد رابط https.
3. **التثبيت:** افتح الرابط ← Chrome/Edge على اللابتوب: أيقونة ⊕ في شريط العنوان — Android: ⋮ ← تثبيت التطبيق — iPhone: Safari ← مشاركة ← Add to Home Screen.
4. **في الأبلكيشن:** الإعدادات ← الصق الرابط وكلمة السر ← فعّل الإشعارات.
5. (اختياري) في Apps Script شغّل `setupDailyDigest` مرة ← ملخص يومي على الإيميل الساعة 9 الصبح.

> الشرح بالتفصيل موجود جوه الأبلكيشن في صفحة **"دليل الربط والتثبيت"**.

## ملاحظات
- البيانات بتفضل في الشيت بتاعك. الأبلكيشن نفسه مفيهوش أي بيانات عملاء، فرفعه على Netlify آمن.
- الأبلكيشن بيقرا الشيت زي ما انت كاتبه (تواريخ بأشكال مختلفة، "خالص"، "200 ريال"، "(500-1700)"…). الصفوف اللي فيها نقص بتظهرلك في فلتر "محتاجة مراجعة".
- الريال بيتحول لجنيه بسعر تقدر تغيره من الإعدادات.
- بيشتغل من غير نت بآخر نسخة محفوظة، والإضافات الجديدة بتتبعت للشيت أول ما النت يرجع.
- لو عدّلت `Code.gs` بعدين: Deploy ← Manage deployments ← ✏️ ← New version.

## الملفات
```
index.html, styles.css         الواجهة
js/app.js                      الشاشات والتفاعل
js/data.js                     قراءة وفهم بيانات الشيت
js/insights.js                 التحليلات والأفكار والتذكيرات
sw.js, manifest.webmanifest    التثبيت والعمل بدون نت والإشعارات
apps-script/Code.gs            الكود اللي بيتركب في الشيت
تشغيل على اللابتوب.bat          تجربة سريعة على اللابتوب من غير رفع (محتاج Python)
```
